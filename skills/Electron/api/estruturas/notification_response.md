# Objeto NotificationAction

- `actionIdentifier` string - A string identificadora da ação que o usuário selecionou.

- `date` number - A data de entrega da notificação.

- `identifier` string - O identificador único para essa solicitação de notificação.

- `userInfo` Record<string, any> - A dictionary of custom information associated with the notification.

- `userText` string (opcional) - O texto inserido ou escolhido pelo usuário.
