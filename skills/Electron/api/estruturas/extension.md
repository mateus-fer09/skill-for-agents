# Extension Object

- `id` string

- `manifest` qualquer - cópia dos [dados do manifesto da extensão](https://developer.chrome.com/extensions/manifest).

- `name` string

- `path` string - O caminho do arquivo da extensão.

- `version` string

- `url` string - A URL `chrome-extension://` da extensão.
