# ResolvedEndpoint Object

- `address` string

- `family` string - Um dos seguintes:

  - `ipv4` - Corresponds to `AF_INET`

  - `ipv6` - Corresponds to `AF_INET6`

  - `unspec` - Corresponds to `AF_UNSPEC`
