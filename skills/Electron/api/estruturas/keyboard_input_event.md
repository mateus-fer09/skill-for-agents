# Objeto KeyboardInputEvent herda de `InputEvent`

- `type` string - O tipo de evento, pode ser `rawKeyDown`, `keyDown`, `keyUp` ou `char`.

- `keyCode` string - O caractere que será enviado como o evento do teclado. Should only use valid [Accelerator](/pt/docs/latest/tutorial/keyboard-shortcuts#accelerators) key codes.
