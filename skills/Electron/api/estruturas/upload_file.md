# Objeto UploadFile

- `type` 'file' - `file`.

- `filePath` string - Caminho do arquivo a ser carregado.

- `offset` Integer (optional) - Defaults to `0`.

- `length` Integer (optional) - Number of bytes to read from `offset`. O padrão é `0`.

- `modificationTime` Double (optional) - Last Modification time in number of seconds since the UNIX epoch. O padrão é `0`.
