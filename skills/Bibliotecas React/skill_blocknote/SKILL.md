# Skill BlockNote

## Identidade

Esta Skill organiza conhecimento técnico da documentação oficial do **BlockNote**, editor rich-text baseado em blocos para React, extensível, com colaboração em tempo real e componentes de UI prontos para uso.

Fontes autorizadas desta Skill:
- https://www.blocknotejs.org/docs
- https://www.blocknotejs.org/examples
- páginas e subpáginas documentais pertencentes a `www.blocknotejs.org` descobertas a partir desses pontos de entrada.

## Quando usar

Use esta Skill quando precisar implementar, configurar, personalizar ou explicar BlockNote, incluindo estrutura de documentos, schemas, blocos, UI React, styling, colaboração, interoperabilidade, eventos, seleção, manipulação de conteúdo e exemplos oficiais.

## Fluxo recomendado para o agente

1. Consulte `index_master.md` para localizar o domínio correto.
2. Leia os arquivos especializados indicados no mapa de contexto.
3. Para APIs do editor, priorize `reference/editor/`.
4. Para estrutura do documento e schemas, priorize `foundations/` e `features/custom_schemas/`.
5. Para componentes visuais React, use `react/components/`.
6. Para padrões de implementação demonstrados oficialmente, consulte `examples/` e siga a URL oficial indicada.
7. Se houver conflito entre a memória do agente e esta Skill, priorize a documentação oficial apontada em `sources_manifest.md`.
8. Não invente APIs ou propriedades ausentes da documentação.

## Regra de proveniência

O conteúdo explicativo desta Skill é uma síntese técnica em português baseada nas páginas oficiais consultadas. Grandes trechos verbatim e exemplos extensos não são redistribuídos; nesses casos, a Skill preserva a finalidade, APIs envolvidas e a URL oficial para consulta do exemplo original.
