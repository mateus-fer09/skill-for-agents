# YJS Utilities

Além da configuração colaborativa, BlockNote expõe utilities para trabalhar programaticamente com documentos Yjs e converter/relacionar blocks com estruturas Yjs.

Use estas APIs quando precisar manipular dados colaborativos fora do fluxo visual do editor, criar versões/snapshots ou integrar persistência baseada em Yjs.

Fonte: https://www.blocknotejs.org/docs/reference/editor/yjs-utilities
