# Cursor & Selections

Use esta referência para:
- ler posição do cursor textual;
- mover cursor;
- ler/alterar seleção;
- trabalhar com blocos afetados por uma seleção;
- implementar UIs contextuais baseadas em cursor/selection.

Não confunda seleção de blocks com seleção inline de texto; confirme o método adequado na página oficial.

Fonte: https://www.blocknotejs.org/docs/reference/editor/cursor-selections
