# Editor API — Overview

Operações gerais documentadas:
- alternar estado editável via `isEditable`;
- foco: `focus()` e `isFocused()`;
- histórico: `undo()` e `redo()`;
- paste programático: HTML, text e Markdown;
- configuração por opções do editor.

Opções documentadas na referência incluem, entre outras: animations, autofocus, defaultStyles, dictionary, disableExtensions, domAttributes, dropCursor, initialContent, links, pasteHandler, resolveFileUrl, schema, setIdAttribute, tabBehavior, tables, trailingBlock, uploadFile e extensions.

Fonte: https://www.blocknotejs.org/docs/reference/editor/overview
