# Manipulating Content

A referência separa manipulação de blocos e conteúdo inline.

## Identificadores
Muitos métodos aceitam um `BlockIdentifier`, que pode ser ID string ou objeto com `id`.

## PartialBlock
Na criação/atualização, campos podem ser opcionais: id, type, props, content e children.

## Operações de bloco
A API documenta leitura, inserção, atualização, remoção, substituição, movimento e nesting. Exemplos oficiais demonstram `insertBlocks`, `updateBlock`, `removeBlocks` e `replaceBlocks`.

## Inline content
A API cobre inserção/leitura de conteúdo, seleção, styles e links. Operações de style incluem adicionar, remover e alternar styles. A referência também documenta criação de links.

Fonte: https://www.blocknotejs.org/docs/reference/editor/manipulating-content
