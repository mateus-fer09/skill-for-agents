# Events

BlockNote fornece eventos/callbacks para mudanças de documento, seleção e outros estados do editor. Em React, hooks específicos podem encapsular listeners; em Vanilla JS, listeners podem ser registrados diretamente na instância.

Use esta referência ao implementar persistência, analytics, sincronização ou UI derivada do estado do editor.

Fonte: https://www.blocknotejs.org/docs/reference/editor/events
