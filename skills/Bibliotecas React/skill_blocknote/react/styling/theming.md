# Styling & Theming

Há três camadas documentadas:

1. **Themes**: mudam rapidamente cores, bordas, sombras e fonte por variáveis/tema.
2. **CSS overrides**: regras CSS próprias podem sobrescrever a aparência do editor.
3. **DOM attributes**: atributos/classes podem ser aplicados para permitir styling/integração específicos.
