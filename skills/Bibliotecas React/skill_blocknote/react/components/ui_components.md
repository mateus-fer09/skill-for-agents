# UI Components

BlockNote fornece UI substituível. As áreas oficiais incluem:

## Formatting Toolbar
Aparece sobre seleção de texto. Pode ser desativada, substituída ou recomposta com itens próprios.
Fonte: https://www.blocknotejs.org/docs/react/components/formatting-toolbar

## Suggestion Menus
Menus acionados por trigger character e filtrados pelo texto digitado. O slash menu é o caso mais comum. Há controllers para fornecer itens e componentes customizados.
Fonte: https://www.blocknotejs.org/docs/react/components/suggestion-menus

## Grid Suggestion Menus
Variante em grade para casos como emoji/mentions.
Fonte: https://www.blocknotejs.org/docs/react/components/grid-suggestion-menus

## Link Toolbar
UI contextual de links.
Fonte: https://www.blocknotejs.org/docs/react/components/hyperlink-toolbar

## File Panel
UI usada em arquivos/imagens para upload/substituição e configuração.
Fonte: https://www.blocknotejs.org/docs/react/components/image-toolbar

## Block Side Menu
Menu lateral associado a blocks, incluindo drag handle e ações customizáveis.
Fonte: https://www.blocknotejs.org/docs/react/components/side-menu

## Portal targets
`BlockNoteView` aceita configuração para direcionar elementos flutuantes a containers/elementos específicos. Overrides por controller podem ter precedência.
Fonte: https://www.blocknotejs.org/docs/react/components
