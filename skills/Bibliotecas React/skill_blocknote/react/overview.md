# React Overview

O pacote React conecta a instância `BlockNoteEditor` à UI e oferece hooks/controllers para reagir ao estado do editor sem transformá-lo em um componente controlado tradicional.

Elementos centrais:
- `useCreateBlockNote`
- `BlockNoteView` (em pacote de UI escolhido)
- hooks de mudança/estado
- controllers de UI
- componentes prontos para toolbars e menus

Fonte: https://www.blocknotejs.org/docs/react/overview
