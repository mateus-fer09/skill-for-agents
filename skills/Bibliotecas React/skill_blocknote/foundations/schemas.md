# Schemas

O schema define os tipos de bloco, inline content e estilos aceitos pelo editor. O schema padrão fornece os tipos built-in; custom schemas podem estendê-lo ou substituí-lo.

Conceitos relacionados:
- `BlockNoteSchema`
- block specs
- inline content specs
- style specs
- inferência de tipos TypeScript a partir do schema

Para customização prática, consulte `features/custom_schemas/overview.md`.

Fonte: https://www.blocknotejs.org/docs/foundations/schemas
