# Recursos de plataforma

## Import
APIs para importar conteúdo de formatos suportados e transformá-lo em blocks.
Fonte: https://www.blocknotejs.org/docs/features/import

## Server-side processing
Há APIs/pacotes para processar documentos fora do browser, úteis para conversão/renderização e pipelines backend.
Fonte: https://www.blocknotejs.org/docs/features/server-processing

## Localization (i18n)
O editor aceita `dictionary`. Pacotes adicionais podem ter dictionaries próprios e devem ser mesclados conforme o recurso utilizado.
Fonte: https://www.blocknotejs.org/docs/features/localization

## Extensions
BlockNote pode ser ampliado com extensions. A documentação e exemplos mostram inclusive integração com extensions TipTap e recursos especializados.
Fonte: https://www.blocknotejs.org/docs/features/extensions
