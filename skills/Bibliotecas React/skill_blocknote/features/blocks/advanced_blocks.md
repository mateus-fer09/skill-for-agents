# Code, Math e Diagram blocks

## Code Blocks
BlockNote possui code block e suporte a syntax highlighting por extensão/pacote documentado. Consulte a página para configuração de linguagens e highlighter.
Fonte: https://www.blocknotejs.org/docs/features/blocks/code-blocks

## Math & Equations
A documentação oferece bloco e inline math em pacote específico, com conteúdo LaTeX e renderização matemática; integração com exportadores é documentada.
Fonte: https://www.blocknotejs.org/docs/features/blocks/math

## Diagrams
Há suporte documentado a diagrams com Mermaid e integração com exportadores.
Fonte: https://www.blocknotejs.org/docs/features/blocks/diagrams
