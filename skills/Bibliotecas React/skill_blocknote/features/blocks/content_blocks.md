# Blocos de conteúdo padrão

## Typography
Inclui paragraph e heading. Heading possui opções documentadas como nível padrão, níveis permitidos e suporte a toggle headings.
Fonte: https://www.blocknotejs.org/docs/features/blocks/typography

## List Types
A documentação separa os tipos de lista incluídos no schema e suas propriedades/comportamento.
Fonte: https://www.blocknotejs.org/docs/features/blocks/list-types

## Tables
Tabelas utilizam `TableContent`. Recursos avançados podem incluir configurações e manipulação específica de rows/cells/headers conforme a versão documentada.
Fonte: https://www.blocknotejs.org/docs/features/blocks/tables

## Embeds
Agrupa blocos de mídia/arquivo e respectivos props, upload/URLs e renderização.
Fonte: https://www.blocknotejs.org/docs/features/blocks/embeds
