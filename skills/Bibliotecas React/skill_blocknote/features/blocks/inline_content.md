# Inline Content

Tipos padrão incluem `StyledText` e `Link`.

`StyledText` contém texto e um mapa de styles. `Link` contém `href` e conteúdo textual estilizado. A configuração `links` do editor permite customizar renderização/comportamento de links.

Para criar tipos inline novos, use custom schemas e consulte `features/custom_schemas/overview.md`.

Fonte: https://www.blocknotejs.org/docs/features/blocks/inline-content
